# Docutalk theme

Modern purple + white metallic. Brand purple is reserved for CTAs and focus rings; page surfaces stay cool silver-white.

## Tokens

| Token | Hex / value | Usage |
|-------|-------------|--------|
| `--color-bg` | `#FAFBFF` | Page background |
| `--color-bg-muted` | `#F3F4F8` | Muted panels |
| `--color-surface` | `#FFFFFF` | Cards, inputs |
| `--color-brand` | `#6D28D9` | Primary CTA |
| `--color-brand-hover` | `#5B21B6` | CTA hover |
| `--color-brand-muted` | `#8B5CF6` | Accents |
| `--color-brand-subtle` | `#EDE9FE` | Focus ring / soft fill |
| `--color-border-metal` | `#C5C8D0` | Metallic borders |
| `--color-border-subtle` | `#E2E4EA` | Dividers |
| `--color-text` | `#0F172A` | Body text |
| `--color-text-secondary` | `#64748B` | Secondary text |
| `--gradient-metal` | white → silver | Surfaces / secondary buttons |
| `--gradient-metal-button` | violet → deep purple | Primary buttons |
| `--gradient-hero` | white → lavender-silver | Page atmosphere |

## Rules

1. Do not wash entire pages in purple.
2. Prefer thin silver borders over heavy shadows.
3. Metallic look comes from gradients and inset highlights, not neon glow.
4. Inter Tight for UI typography.
